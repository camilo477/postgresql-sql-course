1. ¿Qué es CREATE TABLE?

CREATE TABLE es una instrucción SQL que permite 
definir una nueva tabla dentro de una base de datos.

recuerda que una tabla contiene:
- Columnas.
- Tipos de datos.
- Filas o registros.
- Restricciones, cuando las definimos.

2. Sintaxis básica

CREATE TABLE nombre_tabla (
    columna1 tipo_dato,
    columna2 tipo_dato,
    columna3 tipo_dato
);

3. Ejemplo práctico




CREATE TABLE books (
    id INTEGER PRIMARY KEY,
    title TEXT,
    published_at DATE
);

PRIMARY KEY:

id almacena números enteros.
No permite valores duplicados.
No permite valores NULL.
Identifica de manera única cada registro.

Bloque 2 — Parte 3: NUMERIC y precisión monetaria

1. NUMERIC(precision, scale)

balance NUMERIC(12, 2)

Precision (12)
Cantidad máxima total de dígitos.
Scale (2)
Cantidad de dígitos después del separador decimal.

2. TEXT vs. VARCHAR

name TEXT
name VARCHAR(50)

La diferencia principal es que VARCHAR(50) establece un límite de 50 caracteres, mientras que TEXT no establece un límite explícito.

Bloque 2 — Parte 4: SERIAL e IDENTITY

1. El problema de los identificadores

PostgreSQL tiene mecanismos de generación automática.

2. SERIAL

CREATE TABLE books (
    id SERIAL PRIMARY KEY,
    title TEXT
);

PostgreSQL crea una secuencia asociada a la columna y utiliza sus valores para generar identificadores.

3. IDENTITY

PostgreSQL también admite columnas IDENTITY.

CREATE TABLE books (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT
);

Esta es una forma moderna, basada en el estándar SQL, de generar identificadores automáticamente.

Existen dos modalidades:
- GENERATED ALWAYS AS IDENTITY: normalmente exige utilizar el valor generado por PostgreSQL, salvo que se indique explícitamente una sobrescritura.
- GENERATED BY DEFAULT AS IDENTITY: genera el identificador automáticamente, pero permite proporcionar uno manualmente.
